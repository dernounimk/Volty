# Volty

Volty is a modern e-commerce web application designed to provide a fast, seamless, and user-friendly online shopping experience. The project follows a clear separation between frontend and backend for easier maintenance and scalability.

🌐 **Live Demo**: [volty-store.vercel.app](https://volty-store.vercel.app)

---

## ✨ Key Features

- 🛒 **Interactive Shopping Cart**: Easily add, update, or remove products.
- 🚀 **High Performance**: Optimized for speed and a smooth user experience.
- 📱 **Fully Responsive**: Works flawlessly on desktops, tablets, and mobile devices.
- 🔧 **Clean Architecture**: Separate frontend and backend code for better organization.

---

## 🛠️ Technologies Used

- **Frontend**:
    - JavaScript (98.8%)
    - CSS (1.1%)
    - HTML (0.1%)
- **Backend** (assumed Node.js + Express):
    - Node.js / Express
- **Other Tools**:
